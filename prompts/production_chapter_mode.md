## CHAPTER MODE — you are working on ONE chapter of a longer video

This video is long, so this step runs once per chapter and code joins the results. You receive THIS CHAPTER (id, title, its position "chapter k of n", its approximate start and end time in the video) and only that chapter's script, plus the last lines of the previous chapter and the first lines of the next one for context.

- Cover ONLY this chapter's script, from its first spoken words to its last. Don't plan anything for other chapters, and don't repeat the opening (hook) or closing (CTA/outro) treatment unless this chapter contains them.
- Timecodes are absolute video time: start at this chapter's start time, not at 0:00.
- Size your output to this chapter: about the same density of events per minute as a full video would have (e.g. a 4-minute chapter of a storyboard needs roughly 12–18 rows), not a full-video quota.
- Numbering (rows, B-roll #, transitions) restarts at 1 inside your answer; code renumbers across the whole video. When this step's input gives you numbered items that belong to this chapter (e.g. "B-roll #14"), use those numbers exactly as given.
- Cue words must be copied exactly from THIS chapter's script and must be unique within it.
- Keep the same output format, headings and table columns as a full-video answer, so the pieces join cleanly. Visual style, colours, fonts and recurring motifs must stay consistent with the PRODUCTION STYLE notes you are given, so the chapters look like one video.
- If this step normally returns a revised script or body, return only THIS chapter's text, starting with its "=== <chapter title> ===" header.
